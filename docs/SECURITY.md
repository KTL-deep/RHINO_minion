# Модель безопасности

## Граница доверия

LLM и backend считаются недоверенными источниками аргументов. Только Rhino plugin имеет право изменять активный RhinoDoc, и только через зарегистрированные типизированные инструменты.

## Правила V0

- Слушать только `127.0.0.1` и `::1`.
- Проверять session secret при handshake.
- Ограничивать размер сообщений, batch и время выполнения.
- Валидировать числа, GUID, строки, диапазоны и типы операций.
- Не выполнять Python, C#, shell-команды или динамически загруженные сборки.
- Не читать и не отправлять произвольные локальные файлы.
- Не хранить секреты в git или логах.
- Не отправлять полную геометрию в LLM без явного пользовательского действия.

## Сообщение об уязвимости

До появления публичного security-канала не публикуйте секреты и воспроизводимые exploit-данные в открытых issue.
