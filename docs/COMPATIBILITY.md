# Совместимость с Rhino 8

## Требование

Один дистрибутив RHINO Minion должен работать на всех сервис-релизах Rhino 8 for Windows, начиная с Rhino 8.0.

## Правила реализации

- Plugin target framework: `.NET Framework 4.8` (`net48`).
- Compile-time dependency: RhinoCommon `8.0.23304.9001`.
- Запрещено напрямую использовать RhinoCommon API, появившиеся после Rhino 8.0.
- Если новая возможность требует позднего API, она реализуется через feature detection и fallback либо включается только после отдельного решения о повышении минимальной версии.
- Версия Rhino проверяется при запуске, но более новый Rhino 8 не блокируется.
- Все wire-протоколы и geometry tools не должны зависеть от номера сервис-релиза.

## Матрица проверки релиза

Перед выпуском плагин проверяется минимум на:

1. Rhino 8.0 — нижняя граница совместимости.
2. Rhino 8.16.25042.13001 — текущая пользовательская установка.
3. Последний стабильный Rhino 8 SR — верхняя граница.

Для каждой версии проверяются загрузка `.rhp`, команда `RhinoMinion`, WebSocket handshake, пять инструментов V0, batch Undo и обработка ошибок.

Автоматические тесты проверяют код против RhinoCommon 8.0. Реальные Rhino integration smoke tests остаются обязательными, поскольку одной компиляции недостаточно для подтверждения runtime-совместимости.
